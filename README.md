# 🚀 My C Programming Journey

Welcome to my repository! This project is a collection of C programs I've developed while learning the fundamentals of computer science and logic building.

## 📌 About This Project
This repository serves as a personal archive of my progress in C programming. It includes various real-world logic implementations, from basic calculators to grading systems.

## 🛠️ Concepts Covered
- Variables & Data Types
- Control Structures (`if-else`, `switch-case`)
- Logical Operators (`&&`, `||`)
- Arithmetic Calculations
- Code Optimization

## 📂 Featured Programs
- **Electricity Bill Calculator:** A smart system that calculates monthly bills based on unit slabs with discount logic.
- **Student Result System:** Evaluates marks for multiple subjects and determines overall pass/fail status.
- **Simple Calculator:** A menu-driven application using `switch-case`.
- **Salary Calculator:** Basic logic for employee payment processing.

## 🎯 Future Goals

- Transitioning into Cyber Security concepts.
